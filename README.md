## Hey 👋

I'm Mohammad — a software engineer from Amman, Jordan. I graduated from **Al Hussein Technical University** with a B.Sc. in Computer Science (Excellent GPA), and I've been building things ever since.

My work life has two sides, and I like it that way:

### ☀️ By Day

I'm a **Software Engineer at ZagTrader**, where I build the infrastructure that powers capital markets. Settlement messaging, real-time feeds, cryptographic licensing — the kind of systems where things *have* to work.

What I've built there:
- **Swift Suite** — an end-to-end SWIFT securities-settlement platform (ISO 15022 MT540–564) with an async .NET engine, a multi-gateway bridge (Fineksus, Tadawul/Edaa, SFTP), and a React + SignalR monitor with maker-checker approval and 2FA.
- **FixPortal** — a FIX protocol admin tool that parses and diffs messages against a 150+ tag dictionary with per-market rules.
- **ZagKeyGenWeb** — hardware-bound software licensing using TripleDES, HMAC-SHA256, and AES-256/PBKDF2.
- **Market-data connectors** — CMC Markets FX (FIX), IDC historical bars, and OKX exchange (WebSocket v5, HMAC-signed).

`C#` `.NET 10` `ASP.NET Core` `SignalR` `React` `SQL Server` `IKVM` `Azure Key Vault`

### 🌙 By Night

I design and ship my own products. It's where I experiment, learn fast, and turn ideas into things people can actually use.

- **[Odispear](https://n0tmot.com)** — a Discord-style community platform with servers, channels, real-time messaging (Socket.IO), and LiveKit voice/video with RNNoise noise filtering. Node/Express + PostgreSQL + Redis, deployed on AWS. &nbsp;[💻 Code](https://github.com/MohdOtaqi/Odispear)
- **[MedGuard](https://github.com/Mo-Otaqi/Graduation-Project-MedGuard)** — my graduation project. A health companion app that reads live vitals from a BLE heart-rate sensor (GATT 0x180D), shares them in real time via Firestore, runs AI health analysis through a Gemini Cloud Function, and pushes GPS emergency alerts over FCM.
- **[MOT](https://github.com/MohdOtaqi/MOT)** — a social network for gamers. LFG matchmaking, real-time chat, 300+ game database (RAWG API), content moderation, and RevenueCat subscriptions. Built because I wanted a better way to find teammates.
- **[Masra](https://github.com/MasraAppJo/masra-platform)** — an Islamic education platform around Al-Aqsa and Jerusalem. Offline-first Flutter app with AR/EN localization, a Node/Prisma API on Supabase (RLS), and automated GitHub Actions APK builds.
- **Sehleh** — an on-demand services marketplace. Dual customer/provider Flutter apps, PostGIS geolocation, live GPS tracking, in-app chat, and Stripe + Tap payments.
- **[Sabaq](https://github.com/aboodjq/SabaqHackathon)** — Quran memorization with AI recitation grading. Whisper STT fuzzy-matched against riwaya text. I owned the Django/DRF backend and the OAuth2 proxy.
- **Tabayyun** — an Arabic news credibility checker that scores articles using LLM analysis and detects image tampering via EXIF, Error-Level Analysis, and Sightengine.
- **FactQuest** — a gamified media-literacy trainer with XP, streaks, and guided lessons across eight misinformation modules.

`Flutter` `React Native` `React` `Node.js` `PostgreSQL` `Firebase` `Supabase` `LiveKit` `AWS` `Django`
